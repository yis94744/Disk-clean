# 03 - 修复方案文档

对应 `02-问题复现文档.md` 中的 P1~P7、P9。P8/P10/P11 为信息项不修复。
每项给出：改动点、具体方案、验证方法。

---

## F1（修 P1）注册表扫描 AttributeError

- **文件**：`core/registry_cleaner.py`
- **改动**：`_check_vals()` 与 `_startup_entries()` 中的
  `self._is_broken_command(d)` → `RegistryIssue._is_broken_command(d)`（2 处）。
- **验证**：`RegistryScanner()._invalid_paths()` 不再抛异常并返回 issue 列表；
  GUI「扫描注册表」能正常完成。

## F2（修 P7）QThread.run 异常兜底

- **文件**：`core/registry_cleaner.py`
- **改动**：`RegistryScanner.run()` 用 try/except 包裹三个阶段，
  捕获异常时 `progress.emit("注册表扫描出错: ...")` 并**始终** `finished.emit(issues)`，
  保证 UI 不会停留在"进行中"。
- **范围说明**：其余 QThread（ScanWorker/DupFinder/_ProcessWorker 等）页面侧已有
  cancel/wait 保护且本轮实测未见崩溃路径，本次只修实测复现的 RegistryScanner；
  其余线程留待后续统一治理（写入审计备注）。
- **验证**：人为注入异常时 UI 能收到完成信号并显示错误信息（离屏验证）。

## F3（修 P2）启动管理 HKCU hive 常量错误

- **文件**：`ui/startup_mgr.py`
- **改动**：删除魔法数字，直接使用 `winreg.HKEY_CURRENT_USER` / `winreg.HKEY_LOCAL_MACHINE`
  构造 `paths`，注释同步更正。
- **验证**：GUI 启动管理页出现 HKCU Run 的全部值（ctfmon/OneDrive/Edge 等）；
  离屏加载 `_entries` 中 source 为 HKCU 的数量与注册表一致。

## F4（修 P3）启动文件夹过滤 desktop.ini

- **文件**：`ui/startup_mgr.py`
- **改动**：两个启动文件夹遍历处，`os.listdir` 后跳过 `desktop.ini`（不区分大小写）。
- **验证**：启动管理页不再出现 desktop.ini 行。

## F5（修 P4）大文件页类别中文映射补全

- **文件**：`ui/large_files.py`
- **改动**：`CAT_NAMES` 补充 helpers 类别全集的映射：
  `System:系统驱动, Program:安装程序, Mobile App:移动应用, Web/Net:网络/网页, Shortcut:快捷方式`；
  `CAT_COLORS` 同步补色。
- **验证**：扫描后 .bin/.dll 文件类别显示中文。

## F6（修 P5）安全等级标签中文化

- **文件**：`utils/constants.py`
- **改动**：`SAFETY_LABELS` 文案 `Safe/Clean/Caution/Protected` → `安全/建议清理/谨慎/受保护`。
  （颜色键值不变；harness/脚本只断言 level 数值，不受影响。）
- **影响面**：文件可视化安全列、安全清理表、（已删除的 SafetyBadge 无残留引用）。
- **验证**：GUI 安全列显示中文。

## F7（修 P6）磁盘分析器加回导航

- **文件**：`main.py`、`ui/widgets/sidebar.py`
- **改动**：
  1. `NAV_ITEMS` 在「文件可视化」后插入 `("disk_analyzer", "磁盘分析")`；
  2. `main.py` 的 `PAGE_CLASSES`/`PAGE_TITLES` 增加 `disk_analyzer`；
  3. `sidebar.py` 的 `_CARTOON_COLORS` 增加 key，`_make_cartoon_icon` 增加一个
     treemap 色块风格的绘制分支（四个小矩形拼图）。
- **验证**：侧边栏出现「磁盘分析」，点击进入，扫描 X: 后 TreeMap 渲染、文件列表填充。

## F8（修 P9）一键清理移入后台线程

- **文件**：`ui/safe_cleaner.py`
- **改动**：
  1. 新增 `CleanWorker(QThread)`：`run()` 调 `engine.clean(items)`，结束后发 `clean_finished(list)`；
  2. `_clean()`：确认后禁用「一键清理」按钮、状态栏提示"清理中..."，启动 CleanWorker；
  3. `clean_finished` 槽：恢复按钮、汇总 freed 大小并刷新各条目状态文本。
- **验证**：离屏 harness 触发 `_clean()`（选无害项），断言：按钮在清理期间禁用、
  结束后恢复、结果汇总正确、无跨线程 UI 调用告警。

## F9（修 P12）跳过 MUI 间接字符串

- **文件**：`core/registry_cleaner.py`
- **改动**：`_is_broken_command` 开头增加守卫：值以 `@` 开头直接返回"非失效"
  （MUI 间接字符串 `@dll,-index` 指向资源文本，不是路径，也不应被清理）。
- **验证**：离线构造 `@%SystemRoot%\system32\oregres.dll,-203` 值不被判失效；
  GUI 重新扫描后列表中不再出现 `dll,-N` 类条目。

## 不修复项及理由

| 项 | 理由 |
|----|------|
| P8 进程刷新 15s | 采样语义（CPU% 需要两次测量）决定下限；改为异步提示超出本轮范围，记录即可 |
| P10 AX 复选框 | Qt/UIA 桥接限制，非应用缺陷；真实鼠标操作正常 |
| P11 一次性异常 | 无法复现、无日志，不盲目改代码 |
